# 🌐 ICF Igreja – Website

## 📌 Sobre o projeto

O **ICF Igreja** é um site web desenvolvido para representar uma igreja, com o objetivo de disponibilizar informações, conteúdos e possivelmente conectar membros e visitantes.

O projeto está hospedado na plataforma Netlify, o que permite fácil acesso online e deploy contínuo.

---

## 🎯 Objetivo

O site tem como principais finalidades:

* Apresentar a igreja e sua identidade
* Divulgar informações como cultos, eventos e contatos
* Servir como ponto de conexão com a comunidade
* Disponibilizar conteúdos digitais (ex: mensagens, estudos, links)

---

## 🛠️ Tecnologias utilizadas

* HTML, CSS e JavaScript
* Framework front-end (possivelmente Angular)
* Hospedagem via Netlify

---

## 🚀 Funcionalidades

* Página inicial institucional
* Navegação entre seções
* Estrutura para conteúdos religiosos
* Interface simples e responsiva

---
